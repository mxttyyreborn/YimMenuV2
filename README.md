
# YimMenuV2

Updated for **b1013.17**

## How to use:

1. Download YimMenu V2 from: [![yimmenuv2](https://img.shields.io/badge/YimMenuV2-DOWNLOAD-blue)](https://github.com/mxttyyreborn/YimMenuV2/releases/download/nightly/YimMenuV2.dll)
2. Download Xenos Injecter from UC: https://www.unknowncheats.me/forum/general-programming-and-reversing/124013-xenos-injector-v2-3-2-a.html
3. Inject YimMenuV2.dll to GTA5_Enhanced.exe when in the Main Menu.
4. Enter Story Mode
5. Enter an Invite Only / Closed Friend Session via the Pause Menu
6. Press "DELETE" / "DEL" to open the menu when in online.
7. Happy Modding!
